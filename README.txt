# 公司午餐 2.0｜線上版

這一版已改成使用 Supabase 雲端資料：
- restaurants：餐廳資料
- notes：小紙條
- menu_images：菜單圖片紀錄
- Storage bucket `menus`：菜單圖片檔案
- app_settings：編輯模式密碼雜湊

使用方式：
1. 一般同事直接開網站即可查看、抽午餐、看菜單。
2. 點「🔐 編輯模式」後輸入原本的管理密碼 83605595。
3. 編輯模式可新增／修改／刪除餐廳、增加／刪除小紙條、上傳／刪除菜單圖片。
4. 手機版已加強自適應。

注意：
目前依照「公司同事共用一組編輯密碼、不需要登入」的需求，
Supabase 的匿名寫入權限仍然存在；真正的限制主要由網站編輯模式控制。
如果之後需要防止知道網站技術的人繞過前端密碼，可再升級成真正的登入／驗證權限。
